📧 AI-Powered Cold Email Generator

An AI-based application that generates professional and personalized cold emails using NLP.
Designed as an academic project for college submission under SPPU.

📌 Overview

Writing cold emails manually is time-consuming and repetitive.
This project automates email generation by using template-based NLP logic with personalization features like tone, industry, and recipient details.
It also includes an analytics dashboard for email insights.

✨ Key Features

Automated cold email generation

Personalization (name, company, industry, pain point)

Multiple tones & email structures

Interactive Streamlit UI

Analytics dashboard (word count, tone & industry stats)

Model saving using Pickle

🧠 Methodology (Brief)

Synthetic dataset generation using Python

Text preprocessing and validation

Template-based NLP email generation

Visualization using Plotly

🛠️ Tech Stack

Python

Streamlit

Pandas, NumPy

Scikit-learn

Plotly

Pickle

▶️ How to Run

pip install -r requirements.txt
streamlit run app.py

📊 Results

50+ emails generated

Covers 10 industries & multiple tones

High personalization & readability
